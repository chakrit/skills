Design styles

Each style below has a few preview pages, each a different fictional business. Click a preview to open it full size, then tell the agent which style you want.

Andy Clarke

Concept-led art direction: one idea per business, poster and magazine layouts, bold display type, few colours in unequal amounts.

  • Bike repair shop
  • Family dental practice
  • Record shop listening night
  • Japanese: Fushimi sake brewery
  • Thai: Chiang Mai tailor

Jason Santa Maria

Typography first: a fixed frame with pieces that earn their own art direction, an off-centre reading column, a calm field with one rare accent.

  • Edinburgh poetry quarterly
  • Hay-on-Wye secondhand bookshop
  • Portland type foundry
  • Thai: Bangkok literary quarterly
  • Japanese: Tokyo essay publisher

Dan Cederholm

Handcrafted bits: a quiet page warmed by found lettering, one orange, a badge grown from a found object.

  • Salem coffee roaster
  • Asheville screen-print shop
  • Leeds woodworking club
  • Thai: Ayutthaya knife smith
  • Japanese: Kanazawa coffee house

Frank Chimero

Write the design first, then set it plainly: one sentence, an index, a split, going with the grain of the web.

  • Portland bookbinder
  • Brooklyn lecture series
  • Melbourne architecture practice
  • Thai: Chiang Rai translator

Rob Weychert

One stated system, one bent convention: listings, ledgers and data features built on a strict scale.

Scott Kellum

Type-designer method: a master size per role, eased curves between them, a drawn grid, a large serif opening paragraph.

Simon Collison

Motive-led miscellany: a small kit of colours and type, a voice in every label, honest surfaces, a picture set against the type.

Yugo Nakamura

Composition of logics: one behaviour moved by a real force, such as the clock or the pointer, with a plain list beside it. These previews need JavaScript.
