# Orgs

Org controls on this machine. Updated by machine control only. Point
`projects_registry` in `control.toml` at this file: `scripts/` parses the table, so
keep its six columns. Org is chakrit's short org slug; Checkout is relative to `root`
(`~/Documents`), e.g. `datawow/control`; Window and Agent pane are tmux IDs (`@12`,
`%34`).

| Org | Checkout | Window | Agent pane | Backend | Assignment |
| --- | -------- | ------ | ---------- | ------- | ---------- |

## GitHub orgs

One line per org: `- <org slug> → <GitHub org>`.
