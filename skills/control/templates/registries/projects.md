# Projects

Project controls in this org. Updated by the org control only. Project is a lowercase
slug and the name of its folder, `~/Documents/<org>/<project>`. Status is `initiating`
from the row's first write during "Initiate an agent", and `initiated` once you accept
the agent's report that everything is done. `scripts/control-agents` does not read this
file; it finds each agent's pane by its `@agent` tmux tag.
