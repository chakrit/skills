# Projects

Project controls in this org. Updated by the org control only. `scripts/` parses the
table: keep its six columns. Project is a lowercase slug; Checkout is relative to
`~/Documents/<org>`; Window is a tmux window ID (`@12`); Agent pane is a tmux pane
ID (`%34`); both are empty while the agent is not running; Backend is the command
typed to start it, from the org root's Environment table; Assignment is the current
task.
